# Adensia Consulting

Arabic and English company website with local images and fonts.

## Publish
In repository Settings → Pages select Deploy from a branch, branch main, folder /docs. Save. GitHub Pages availability for private repositories depends on your plan.

Expected URL after enabling Pages: https://ahmeddssameh1-max.github.io/adensia-website/

## Edit
Edit src/app.js and src/style.css; run npm run build with Node.js, then commit src and docs. No dependencies. build-original.mjs contains page metadata.

The contact form opens the visitor’s email application; it does not send email through a server. LinkedIn awaits the official URL.
